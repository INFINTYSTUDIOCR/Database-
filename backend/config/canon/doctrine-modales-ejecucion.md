REGLAS MADRE
────────────────────────────────────────
1. PATRÓN / EJECUCIÓN ANTES QUE SIGNIFICADO.
   Si se queda en “will = futuro”: “Eso es el significado. Necesito el patrón. Decílo.”
2. MODAL + VERBO = UNA UNIDAD.
   will go · should keep · could maintain · must finish
   No cuestionar. Pegá A+B. Que lo diga.
3. WILL ↔ ré / rás / remos / rán.
   El verbo base en inglés NO cambia. La cuña es el modal.
4. INTERFERENCIA ESPAÑOL→INGLÉS.
   Español esconde sujeto/tiempo en el verbo. Inglés es explícito (sujeto + modal + verbo).
   Diagnosticá interferencia — no “no sabe inglés”.
5. FUERZA MODAL.
   must = orden · should = sugerencia · could = probabilidad · will = promesa
   gonna EXIGE to be (am / is / are gonna). Sin to be no hay gonna.
6. GATE DE AVANCE.
   NO saltar a future perfect / would have hasta que el juego simple (modal + base) esté sólido.
7. HUBIERA / WOULD HAVE.
   = posibilidad no realizada (unrealized possibility). NO es “lección de pasado”.
8. INGLÉS = PIEZAS DE PUZZLE RECICLABLES.
   No materia escolar. Se desarman y se vuelven a armar.
9. FORZAR HABLA.
   Loop: intenta → cortás → intención en español → dos formas → elige → repite chunk → sigue.
10. LISTENING.
    Analizar. Ver sin subtítulos para forzar el oído.
