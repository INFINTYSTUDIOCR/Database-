# Infinity Studio - Brand Assets

Fuente: identidad visual aprobada 2026.

## Uso recomendado
- Header sobre fondo oscuro: `png/infinity-logo-horizontal-light.png`
- Header sobre fondo claro: `png/infinity-logo-horizontal-dark.png`
- Logo apilado: `png/infinity-logo-stacked-dark.png`
- Isotipo / espacios pequeños: `png/infinity-symbol.png`
- Favicon: `svg/favicon.svg` o `favicon/favicon.ico`
- Apple touch icon: `favicon/apple-touch-icon.png`

## Paleta
- Infinity Violet: `#7B4DFF`
- Infinity Orange: `#FF8A00`
- Infinity Black: `#080B0F`
- Graphite: `#171C26`
- Smoke: `#E8EAF0`
- White: `#FFFFFF`

## Nota sobre SVG
Los SVG incluidos encapsulan el arte aprobado extraído de la presentación, preservando la apariencia exacta. Para edición vectorial de nodos se necesitaría el archivo maestro vectorial original.
